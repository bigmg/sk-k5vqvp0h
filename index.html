ทำช่องคลิปสั้นแนวตั้ง
โดยคุยกับ Claude จนได้คลิปพร้อมอัป

คุณคุยกับ Claude ใน VS Code ให้ช่วยคิดเรื่อง เขียนบท ทำเสียง หาภาพ และประกอบคลิป แล้วได้ไฟล์ .mp4 ไปอัปขึ้น YouTube Shorts และ Facebook Reels ได้เลย ใช้ได้กับทุกแนวช่อง ไม่ว่าจะเล่านิยาย ความรู้ นิทาน หรือเล่าสรุปคลิป

วันที่ 1

เปิดช่อง + ทำ 2 คลิปแรก

คลิปแรกได้ผลดีเกินคาด ส่วนคลิปที่สองติแล้วแก้หลายรอบ ทั้งฮุค ลำดับเรื่อง และภาพ จนได้ "แม่แบบ" ที่ใช้กับคลิปต่อๆ มา วันแรกยังลองผิดลองถูกเยอะ เช่นเพลงที่ให้ AI แต่งเองฟังไม่ดีเลยเปลี่ยนไปใช้เพลงจริง และทำปกแล้วไม่ชอบเลยเลิกทำ

วันที่ 2–3

ทำเป็นรอบ รอบละ 5 คลิป

ร่างบททั้ง 5 ตัวให้ผ่านก่อน แล้วเจนเสียงรวมครั้งเดียวเพื่อประหยัดโควตา ระหว่างนั้นเจอว่าคลิป 40–48 วิคนดูจบมากกว่าคลิป 55 วิ และคนดูไม่ชอบเอฟเฟกต์เด้งหรือสั่น จึงจดเป็นกฎ

วันที่ 4

ดูยอดครั้งแรก แล้วเจอแนวที่ใช่

คลิปแรกได้ 21K วิว ขณะที่คลิปอื่นได้แค่หลักพัน ดูคอมเมนต์แล้วพบว่าคนชอบเรื่องที่ผูกกับชีวิตตัวเอง จึงปรับการเลือกเรื่องทั้งช่องตามนั้น

รอบวันที่ 4

คลิปที่ 18 และ 20 ปัง

คลิปที่ 20 ได้ 400K บน YouTube แต่ได้แค่ 29K บน FB ส่วนคลิปที่ 18 ได้แค่ 1.7K บน YouTube แต่ได้ 195K บน FB จึงอัปทั้งสองที่ทุกคลิปตั้งแต่นั้น

วันที่ 11

รวมทุกอย่างเป็น PLAYBOOK ฉบับเดียว

เอากฎที่จดไว้กระจัดกระจาย ยอดจริงทุกคลิป และผลวิเคราะห์ช่องดังแนวเดียวกัน 800 กว่าคลิป มารวมไว้ไฟล์เดียว ตั้งแต่นั้น Claude ทำคลิปออกมาตรงใจตั้งแต่รอบแรกบ่อยขึ้นมาก

วันที่ 14

ตอนนี้

ทำไปแล้ว 100 กว่าคลิป แต่ไม่ได้อัปทุกตัว คลิปที่ไม่ผ่านมาตรฐานตัวเองก็ไม่อัป ทำเฉพาะเวลาว่าง วันละประมาณ 2 ชั่วโมง ส่วนใหญ่แค่อ่านสิ่งที่ Claude เสนอแล้วสั่งต่อ

ค่ากลางต่อคลิปไม่ได้สูงขนาดนั้นYouTube ประมาณ 9.7K และ Facebook ประมาณ 4K วิวต่อคลิป ยอดรวมส่วนใหญ่มาจากไม่กี่คลิปที่ปัง ซึ่งเป็นธรรมชาติของคลิปสั้น ต้องทำต่อเนื่องหลายคลิปถึงจะเจอตัวที่ปัง

ช่องคุณไม่จำเป็นต้องเป็นแนวเดียวกับช่องนี้ สิ่งที่ใช้ได้กับทุกแนวคือวิธีทำงาน: ให้ Claude ผลิต คุณเป็นคนตัดสิน และทุกครั้งที่ติ ให้จดเป็นกฎลง PLAYBOOK

2ก่อนเริ่ม: เงิน · คอม · เวลา

💰 ค่าใช้จ่ายต่อเดือน
  • Claude ต้องเป็นแพ็กเกจเสียเงิน: Pro ประมาณ $20, Max $100 หรือ $200 (ราคา ณ พ.ย. 2569)
  • เครื่องมืออื่นในระดับ 1 ฟรีทั้งหมด
  • ภาพ AI ฟรีถ้าเจนในเครื่องเอง ถ้าใช้บริการออนไลน์จะมีค่าใช้จ่าย
  • ช่องตัวอย่างใช้แค่แพ็กเกจ Pro รวมค่าใช้จ่ายขั้นต่ำจึงประมาณ $20 ต่อเดือน
💻 คอมพิวเตอร์
  • Windows หรือ Mac รุ่นไม่เก่ามาก RAM 8GB ขึ้นไป พื้นที่ว่าง 20GB ขึ้นไป
  • ไม่ต้องมีการ์ดจอแรง ก็ทำคลิปได้
  • มีการ์ดจอ NVIDIA จะถอดเสียงเร็วขึ้นมาก และเจนภาพ AI ในเครื่องได้ฟรี
⏱️ เวลา
  • ตั้งระบบครั้งแรก: ครึ่งวันถึง 1 วัน
  • หลังจากนั้นทำเป็นรอบ รอบละ 3–5 คลิป
  • เวลาส่วนใหญ่ของคุณหมดไปกับ การเลือกเรื่องและตรวจบท ส่วนงานผลิต Claude ทำให้
  • ช่องตัวอย่าง: รอบละ 4–5 คลิป ใช้ประมาณ 1–2 ชั่วโมง นับจากเตรียมวัตถุดิบจนได้ไฟล์ (วัดจากเวลาของไฟล์จริง) โดยทำแค่ช่วงว่าง วันละประมาณ 2 ชั่วโมง

เปิดช่อง + เปิดเพจ

  1. ใช้บัญชีส่วนตัว ไม่ใช้อีเมลที่ทำงาน (บัญชีบริษัทอาจโดนปิดหรือถูกเรียกคืน)
  2. YouTube: เข้า youtube.com → รูปโปรไฟล์ → สร้างช่อง → ตั้งชื่อและ @handle → ยืนยันเบอร์โทร (ปลดล็อกบางฟีเจอร์ เช่นตั้งภาพปกเอง)
  3. Facebook: สร้าง เพจ แยกจากโปรไฟล์ส่วนตัว (หรือเปิดโหมดมืออาชีพ) แล้วใช้ Meta Business Suite อัปและตั้งเวลาลง
  4. ใช้ชื่อเดียวกันทุกแพลตฟอร์ม ภาพโปรไฟล์และแบนเนอร์ให้ Claude ช่วยทำได้ หลังจากออกแบบหน้าตาช่องแล้ว (ข้อ 7)

5เครื่องมือ + การเชื่อมต่อ

แบ่งเป็น 3 ระดับ แค่ระดับ 1 ก็ทำคลิปได้แล้ว ระดับอื่นค่อยเพิ่มทีหลัง

ระดับเครื่องมือใช้ทำอะไรค่าใช้จ่ายต้องเชื่อมยังไง
1 ต้องมีClaude Code ใน VS Codeตัวหลัก คิด เขียน และสั่งรันทุกอย่างแพ็กเกจ Claude แบบเสียเงินติดตั้ง VS Code → ส่วนขยาย "Claude Code" → ล็อกอินบัญชี Claude
1 ต้องมีPython 3.10+รันสคริปต์ใน Kitฟรีpython.org (Windows ให้ติ๊ก "Add to PATH")
1 ต้องมีffmpegตัด ต่อ ใส่ซับ ผสมเสียง เรนเดอร์ฟรีWindows: winget install Gyan.FFmpeg · Mac: brew install ffmpeg
1 ต้องมีGemini TTSเสียงพากย์ภาษาไทยมีโควตาฟรี (ประมาณ 10 ครั้งต่อวันต่อรุ่น และอาจเปลี่ยนได้)Google AI Studio → Create API key → ใส่ใน .env
1 ต้องมีฟอนต์ไทยซับฟรีGoogle Fonts (Thai) → วางในโฟลเดอร์ fonts/
1 ต้องมีเพลงประกอบเพลงคลอใต้เสียงพากย์ฟรีYouTube Audio Library (ใน YouTube Studio) · incompetech (ต้องใส่เครดิต)
2 ตามแนวภาพ AIฉากของเรื่องแต่ง นิทาน หรือภาพจำลองฟรี ถึงหลักร้อยบาทต่อเดือนมี 3 แบบ: API, เว็บ หรือติดตั้งในเครื่อง (ดูตารางใน GENRES.md) แล้วบอก Claude ว่าเครื่องคุณมีอะไร
2 ตามแนวPexels APIภาพหรือคลิปสต็อกฟรีpexels.com/api → เอา key ใส่ .env
2 ตามแนวyt-dlpโหลดคลิปต้นทางและอ่าน license (แนวเล่าสรุปคลิป)ฟรีpip install -U yt-dlp
2 เสริมfaster-whisperจับเวลาซับให้ตรงคำ และถอดเสียงคลิปฟรีpip install faster-whisper · มีการ์ดจอ NVIDIA จะเร็วกว่ามาก
3 ขั้นสูงYouTube Data APIดึงยอดของช่องตัวเองอัตโนมัติ และค้นหาคลิปฟรีดูขั้นตอนด้านล่าง
3 ขั้นสูงFacebook Graph APIดึงยอดเพจและ Reelsฟรีดูขั้นตอนด้านล่าง
เก็บ key ให้ปลอดภัยใส่ไว้ในไฟล์ .env เท่านั้น (Kit มี .gitignore กันไว้แล้ว) ห้ามแปะ key ในแชตกลุ่ม ในสคริปต์ที่จะแชร์ หรือในภาพหน้าจอ ถ้าหลุดให้ลบ key เก่าแล้วสร้างใหม่ทันที
ขั้นตอนเชื่อม YouTube Data API (ทำครั้งเดียว ประมาณ 15 นาที)
  1. เข้า Google Cloud Console → สร้างโปรเจกต์ใหม่
  2. APIs & Services → Library → เปิดใช้ YouTube Data API v3 (ถ้าจะดูยอดละเอียด เปิด YouTube Analytics API ด้วย)
  3. OAuth consent screen → External → ใส่ชื่อแอปอะไรก็ได้ → เพิ่มอีเมลตัวเองเป็น Test user
  4. Credentials → Create credentials → OAuth client ID → ชนิด Desktop app → ดาวน์โหลดไฟล์ JSON
  5. เปลี่ยนชื่อไฟล์เป็น client_secret.json แล้ววางในโฟลเดอร์ Kit
  6. บอก Claude ว่า "เขียนสคริปต์ดึงยอดคลิปในช่องฉันจาก YouTube API ใช้ client_secret.json" ครั้งแรกจะเด้งหน้าเว็บให้ล็อกอิน แล้วจะได้ token เก็บไว้ใช้ต่อ

❌ ห้าม
  • หนัง การ์ตูน รายการทีวี เพลงดัง และนิยายที่มีลิขสิทธิ์
  • เนื้อหาจากเพจหรือช่องแนวเดียวกัน (เอาได้แค่ไอเดีย)
  • คลิปติด CC แต่เอาของคนอื่นมาอัป (reaction, รวมคลิป)
  • ลบหรือเบลอลายน้ำของเจ้าของ
  • ต้องมีความเป็นต้นฉบับ แพลตฟอร์มลงโทษเนื้อหาที่ซ้ำซากหรือเอาของคนอื่นมาวางเฉยๆ (inauthentic / reused content) คลิป AI ที่ผลิตเป็นจำนวนมากโดยไม่มีมุมของตัวเองก็เสี่ยง
  • ติดป้าย AI ตามที่แต่ละแพลตฟอร์มกำหนด เช่นเสียงพากย์ AI หรือภาพที่ดูเหมือนจริง
  • คนจริงในภาพ: ห้ามบรรยายให้เขาเสียหาย ห้ามใส่คำพูดที่เขาไม่ได้พูด และภาพ AI ห้ามหน้าเหมือนคนจริงหรือดารา
  • เก็บแหล่งที่มาทุกอย่างใน SOURCES.md ถ้าเจ้าของขอให้ลบ → ลบทันที

10หลักที่ใช้ได้ทุกแนว

สรุปจากช่องตัวอย่าง 100 กว่าคลิป เป็นหลักคิด ไม่ใช่สูตรสำเร็จ แต่ละช่องต้องทดลองเอง

01

3 วินาทีแรกตัดสินทุกอย่าง

ประโยคแรกต้องทำให้อยากรู้ต่อ บอกผลลัพธ์หรือความผิดปกติก่อน ห้ามเปิดด้วย "วันนี้จะมาเล่า…" บน Facebook คนหลุดหนักช่วงวินาทีที่ 3–5

02

เรื่องที่ผูกกับชีวิตคนดูชนะ

คนคอมเมนต์เมื่อเรื่องทำให้นึกถึงประสบการณ์ตัวเอง ในช่องตัวอย่าง เรื่องไกลตัวได้ 1–3K วิว ส่วนเรื่องที่คนดูเจอเองได้หลักหมื่นถึงหลักแสน

03

ต้องมีจุดพีค

ก่อนทำถามตัวเองว่า "คนดูได้อะไรกลับไป" จะเป็นหักมุม ข้อมูลใหม่ อารมณ์แรง หรือประเด็นให้เถียงก็ได้ แค่น่ารักหรือดูเพลินไม่พอ

04

อัปทุกแพลตฟอร์ม

คลิปเดียวกันได้ 400K บน YouTube แต่ 29K บน FB ขณะที่อีกคลิปกลับกัน เดาไม่ได้ว่าที่ไหนจะปัง

05

เรื่องเดียว เส้นเดียว

เล่าเรียงเวลา ห้ามแทรกเรื่องรอง ในช่องตัวอย่าง คลิป 40–50 วิคนดูจบมากกว่าคลิปที่ยาวเกิน แต่ตัวตัดสินจริงคือฮุคกับชื่อคลิป

06

ภาษาพูด ไม่ใช่ภาษาเขียน

เขียนเหมือนเล่าให้เพื่อนฟัง ฟังเสียง AI ทุกคลิป คำที่อ่านเพี้ยนให้เปลี่ยนคำในบท แล้วจดลง PLAYBOOK

07

ข้อเท็จจริงต้องเช็คทุกตัว

ระบบถอดเสียงและ AI ให้ตัวเลขผิดได้ ข้อมูลสุขภาพ การเงิน หรือความปลอดภัยต้องมีแหล่งจริงเสมอ

08

ซับต้องตรงเสียงทุกคำ

ถ้าซับสรุปเองหรือเขียนย่อ คนดูจะรู้สึกว่าไม่ตรง ตัวเลขในซับเขียนเป็นเลขอารบิกเพื่อให้อ่านเร็ว

09

ตัดต่อนิ่งๆ ดีกว่าหวือหวา

ซูมกระแทก จอสั่น และแฟลช ทำให้คนดูรู้สึกว่าคลิปกระตุก ภาพเต็มจอแนวตั้งดีกว่าภาพลอยกลางจอ

10

ทำให้ได้ 30 คลิปก่อนตัดสิน

ยอดของคลิปสั้นแกว่งมาก คลิปที่ปังที่สุดของช่องตัวอย่างคือคลิปที่ 20 ดังนั้นอย่าเลิกหรือเปลี่ยนแนวจากยอดแค่ไม่กี่คลิป

  4. แชร์ทันที หรือตั้งเวลา

คำถามที่เจอบ่อย

ลงบ่อยแค่ไหนดี?

สม่ำเสมอสำคัญกว่าจำนวน ถ้าทำได้ให้ลงวันละ 1–2 คลิปทุกวัน ทำเป็นรอบแล้วตั้งเวลาลงล่วงหน้า

กี่วันถึงเห็นผล?

ช่องตัวอย่างมีคลิปแรกที่ได้หลักหมื่นในสัปดาห์แรก และได้หลักแสนตอนคลิปที่ 18–20 ไม่มีอะไรรับประกัน แต่จะรู้ได้ก็ต่อเมื่อทำครบสัก 30 คลิป

YouTube จ่ายเงินตอนไหน?

ต้องเข้าโปรแกรมพาร์ทเนอร์ (YPP) โดยทั่วไปต้องมี 1,000 ผู้ติดตาม และวิว Shorts 10 ล้านใน 90 วัน หรือชั่วโมงดูคลิปยาว 4,000 ชั่วโมงใน 12 เดือน มีรายงานว่าตั้งแต่ 1 ก.พ. 2570 ผู้สมัครใหม่ต้องได้วิว Shorts 20 ล้าน หรือ 8,000 ชั่วโมง (ข้อมูล ณ พ.ย. 2569 ให้เช็คเงื่อนไขจริงที่แท็บ "สร้างรายได้" ใน YouTube Studio)

Facebook จ่ายเงินตอนไหน?

ผ่านโปรแกรม Content Monetization ซึ่งส่วนใหญ่ใช้ระบบเชิญ ดูสถานะได้ที่ Professional Dashboard → สร้างรายได้ (Monetization) แหล่งข้อมูลภายนอกบอกเกณฑ์ไม่ตรงกัน และ Meta มีโปรแกรม Creator Fast Track ให้เข้าเร็วขึ้น ให้เช็คที่หน้าของ Meta เอง

ช่องตัวอย่างมีรายได้หรือยัง?

ยังไม่มีรายได้จากโฆษณา เพราะยังไม่ถึงเกณฑ์ของทั้งสองแพลตฟอร์ม ตอนนี้มีรายได้เล็กน้อยจากการปักตะกร้าสินค้า (affiliate) บนเพจ Facebook

มีรายได้ทางอื่นก่อนถึงเกณฑ์ไหม?

Affiliate (ปักตะกร้า Shopee หรือ Lazada) เริ่มได้ตั้งแต่ช่องยังเล็ก แต่ควรใส่เฉพาะคลิปที่สินค้าเกี่ยวกับเรื่องจริงๆ บอกในแคปชันว่ามีลิงก์ affiliate ห้ามอ้างสรรพคุณเกินจริง และห้ามวางสินค้าในคลิปที่มีหน้าคนจริงจนดูเหมือนเขารับรองสินค้า

ใช้ช่องเดียวทำหลายแนวได้ไหม?

ไม่แนะนำ ระบบแนะนำคลิปของแพลตฟอร์มจะสับสนว่าช่องคุณเหมาะกับใคร ถ้าอยากลองหลายแนว แยกเป็นคนละช่องแล้วใช้ Kit ชุดเดียวกันได้
